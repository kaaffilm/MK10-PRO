# MK10-PRO PyPI Boundary

PyPI is the package distribution surface.

GitHub `main` is the maintained source surface.

## Version boundary

- `1.0.2`: historical package artifact
- `1.0.3`: Witness Release

## v1.0.3 purpose

v1.0.3 makes MK10-PRO installable, locally provable, and capable of emitting a local witness packet.

## Publication rule

v1.0.3 must be published through GitHub Actions Trusted Publishing.

Manual local upload is not authorized.
