# @kaaffilm/mk10-pro

MK10-PRO witness launcher for NPM and GitHub Packages.

This package is not a second implementation of MK10-PRO.

It is a public launcher surface for the canonical MK10-PRO witness commands.

## Use

```bash
npx @kaaffilm/mk10-pro surfaces
npx @kaaffilm/mk10-pro proof
npx @kaaffilm/mk10-pro boundary
npx @kaaffilm/mk10-pro witness
```

## Canonical Python install

```bash
pip install mk10-pro==1.0.3
mk10 proof
mk10 boundary
mk10 witness
```

## Boundary

MK10-PRO verifies deterministic pre-delivery truth.

It does not verify playback, devices, venues, operators, post-delivery behavior, or business outcomes.
